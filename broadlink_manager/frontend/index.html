Dispositivos encontrados

    Cómo funciona esta solapa

    Acá encontrás el hardware. El add-on busca solo al arrancar y cada dos minutos, mandando un mensaje a toda la red. Elegí un dispositivo tocando su fila: las otras solapas trabajan sobre el que esté elegido. 

    Abrís la solapa
   │
   ├─ ¿Aparece tu Broadlink?
   │     SÍ → tocalo para elegirlo. Listo, seguí en Aprender.
   │     NO ↓
   │
   ├─ Tocá "Buscar" (rebarre todas las interfaces de red)
   │     ¿Aparece? → elegilo
   │     NO ↓
   │
   ├─ ¿Está en otra VLAN, red de invitados o WiFi aislada?
   │     → agregalo por IP con el formulario de la izquierda
   │     (el mensaje de búsqueda no cruza esas redes)
   │
   └─ ¿Aparece pero dice "no reconoce este modelo"?
         → botón Modelo → elegí el modelo equivalente
           (pasa con clones y revisiones nuevas de hardware)

    Solo la familia RM aprende códigos. De los demás (enchufes, sensores, cortinas, termostatos) se muestran sus lecturas, y cada fila explica por qué no tiene códigos para aprender. Esos ya los controla Home Assistant por su cuenta.

    Aprender un código

    ¿Querés aprender un control entero? Elegí qué tipo de equipo es y te voy pidiendo los botones uno por uno. 

    
            
    
              
              
              
    
              
    
                
                
                
              
    
            
    
            
    
              
            
    
          
    
        
    

        
    
          
    Cómo funciona esta solapa
    
          
    
            Acá le enseñás al Broadlink los códigos de tus
            controles. El equipo escucha la señal y la guarda tal cual; después
            la puede repetir. IR es un solo paso; RF son dos, porque primero
            hay que encontrar en qué frecuencia transmite el control.
          
    
          
    Tenés que aprender...
   │
   ├─ ¿un control entero (TV, aire, portón)?
   │     → elegí la plantilla, ponele nombre al equipo,
   │       y te va pidiendo los botones uno por uno
   │
   └─ ¿un botón suelto?
         → Aprender IR   o   Aprender RF
                │                  │
                │                  ├─ FASE 1: mantené apretado el botón
                │                  │   → detecta la frecuencia
                │                  │
                │                  └─ FASE 2: soltá y apretalo una vez, corto
                │                      → captura el código
                │                        (si falla, reintentás sin
                │                         repetir el barrido)
                │
                └─ apuntá el control y apretá → captura el código
                            │
                            ▼
                   ┌──────────────────────┐
                   │   Probar el código  │ ← ¿el aparato reacciona?
                   └──────────────────────┘
                      SÍ ↓        NO → Descartar y reintentar
                   Nombrar y guardar
    
          
    
            El código se guarda en el mismo archivo que usa Home Assistant, así
            que quedá disponible al instante para
            remote.send_command. Una vez detectada la frecuencia de un control,
            los demás botones de ese mismo control se aprenden salteando el barrido:
            de unos 30 segundos a unos 3.

   ▼
Tocás un botón
   │
   ├─ se pone VERDE  → el código salió
   └─ se pone ROJO   → algo falló, y te dice qué

¿No aparece ningún botón?
   ├─ ¿eligió un dispositivo en la solapa Dispositivos?
   └─ ¿ese dispositivo ya tiene códigos aprendidos?
    
          
    
            El color queda unos segundos porque un control remoto no informa nada de vuelta:
            sin eso, una pulsación que no hizo nada se vería igual que una que
            funcionó. Un doble toque no dispara dos veces — en un portón
            eso sería abrirlo y cerrarlo enseguida.
          
    
        
    
      
    

      
    
        
    
          
    Códigos guardados
    
          
    
            
            
            
            
            
            
          
    
          
    
        
    

        
    
          
    Cómo funciona esta solapa
    
          
    
            Es la vista de administración: acá se ordena, se corrige y se
            respalda. Los códigos están agrupados por equipo,
            y ese nombre de equipo es exactamente el que va en el parámetro
            device de remote.send_command.
          
    
          
    ¿Qué querés hacer?
   │
   ├─ Ver si un código funciona          → Probar
   ├─ Le puse un nombre confuso          → Editar
   ├─ Lo guardé en el equipo equivocado  → Editar → cambiar el equipo
   ├─ Ya no lo uso                       → Borrar
   │
   ├─ Todo un equipo quedó mal nombrado  → Renombrar (fila del grupo)
   │      ⚠ tus automatizaciones siguen usando el nombre viejo
   │
   ├─ Guardar un respaldo / llevarlo a otro HA   → Exportar
   └─ Traer códigos de otra instalación          → Importar
            │
            └─ ¿hay nombres repetidos?
                  → elegís: dejar los tuyos
                                guardar los dos
                                reemplazar por los del archivo
    
          
    
            Acá aparecen también los códigos que hayas aprendido antes
            por otros medios, porque se lee el mismo archivo que usa Home Assistant. Antes de
            cada modificación se guarda un respaldo en
            /config/broadlink_manager/backups/.

    Entidades creadas
    
            
    
              Aparecen solas en Home Assistant, agrupadas bajo el dispositivo Broadlink.
              No hace falta reiniciar ni editar YAML.
            
    
            
      
          
      
        
      

        
      
          
      Cómo funciona esta solapa
      
          
      
            Acá los códigos se convierten en entidades de Home
            Assistant, para usarlos en automatizaciones, tableros y por voz.
            Aparecen solas, sin reiniciar ni escribir YAML, agrupadas bajo el dispositivo
            Broadlink al que pertenecen.
          
      
          
      ¿Dice "MQTT conectado"?
   │
   NO → abrí "Configuración del broker MQTT"
   │      ├─ ¿tenés el add-on Mosquitto? → se detecta solo,
   │      │                                     revisá el error
   │      └─ ¿tu broker está en otra máquina o puerto?
   │            → cargá servidor, puerto, usuario y contraseña
   │              (al guardar reconecta y te dice si funcionó)
   SÍ ↓
   │
   └─ ¿qué querés crear?
         │
         ├─ Un código, una acción
         │   (abrir el portón, apagar la TV)     → Botón
         │
         └─ Dos códigos, encender y apagar
             (una luz, un ventilador)             → Interruptor
      
          
      
            Los interruptores se crean en modo optimista: un control remoto no informa su
            estado, así que Home Assistant muestra lo último que se le
            pidió. Al dispararse, la entidad envía el código a
            través de Home Assistant y no directo al equipo, para que HA siga siendo el
            único que mantiene la conexión con el Broadlink.
